# 🎙️ Video Transcription com Whisper

Transcreve vídeos do Google Drive (ou local) usando OpenAI Whisper no Google Colab.

[![Abrir no Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/GUUDIN/video-transcription/blob/main/transcrever.ipynb)

## Como usar
1. Clique no badge acima
2. `Runtime → Change runtime type → T4 GPU`
3. Edite os IDs dos vídeos na célula de configuração
4. `Run All`
